## Overview

This repository contains:
- **Machine Learning**: Autoencoder-based anomaly detection models and implementations
- **Web Automation**: Playwright-based bots for scraping and interacting with web platforms
- **Media Tools**: Screen recording and image visualization utilities

The project is primarily built with Jupyter Notebooks (88.8%) for interactive machine learning development and Python scripts (11.2%) for automation tasks.
